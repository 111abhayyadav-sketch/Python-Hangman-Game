🎮 Python Hangman Game

A simple text-based Hangman Game developed using Python.

📌 About Project

This is a beginner-friendly Python project where players guess a hidden word one letter at a time.

🚀 Features

- Random word selection
- 5 predefined words
- Maximum 6 incorrect attempts
- Letter-by-letter guessing
- Win and Game Over messages

🛠️ Technologies Used

- Python
- Random Module
- While Loop
- If-Else
- Lists and Strings

▶️ How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the terminal.
4. Run the following command:

python hangman.py
